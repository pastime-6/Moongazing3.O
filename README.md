# MOONGAZING 3.0 — DJSNOVA

## Run in VS Code
1. Install Node.js LTS from https://nodejs.org/
2. Extract this project folder and open it in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Notes
- React + Vite, React Router, Three.js via React Three Fiber.
- Event time is configurable in `src/App.jsx` at `EVENT_DATE`. It is currently set to 7:00 PM IST on 30 October 2026.
- Registration is frontend-only and saves demo entries to the browser's localStorage.
- Schedule is illustrative. Confirm the actual programme, official contact details, and venue before publishing.
- Gallery images are remote sample astronomy photos, not verified photos from a previous event. Replace them with official event photos when available.
